【三态列（是/否）的判定规则·务必遵守】
1. 只有当原文明确写出否定表述（否认、无、未见、未发现、阴性、不考虑）时，才输出「否」。
2. 原文完全没有提到该项目时，必须留空、什么都不要输出。严禁用「否」表示未提及。
3. 只有原文有明确阳性表述（诊断/病史/检查提示阳性）时才输出「是」，不得推测。
4. 判定「否」必须能在出处块内找到对应的否定句；找不到就留空。

【输出格式】只输出一个 JSON 对象：相关 / 理由 / 条目

条目里每一条 = 表格里的一格：

  类别   必填。决定这条属于哪张表，从这些里选：
         主诉 / 一般情况 / 本次发病 / 诊断-入院 / 诊断-既往 / 诊断-出院 / 诊断-其他 / 溶栓 / NIHSS / 化验 / 检查 / 查体 / 用药 / 既往史 / 出院 / 护理 / 禁忌症 / 其他
  项目   必填。**必须来自上面的列名清单**，一个字都不能改。
  值     必填。下面单独讲怎么填。
  出处   必填。只写块引用，不要抄原文。整块写 p12-b3；
         表格里的某一行写 p12-b4#白细胞（# 后面用该行第一列的实际文字）。

  以下字段**有值才写，没值整个字段省略**（不要写空字符串）：
        单位 / 参考范围 / 异常 / 剂量 / 频次 / 途径 / 时间 / 所见 / 结论

  什么时候用哪个：
    化验   → 单位、参考范围、异常(↑或↓)、时间(采样时间)
    检查   → 所见(影像描述) 与 结论(诊断意见) 分开写
    用药   → 剂量、频次、途径、时间(起止)
    其它类 → 一般只写 值

════════════════════════════════════════════════════════════
【值怎么填】

1. 「是否 / 既往 / 出院是否」开头的列是**三态**：只填「是」「否」，
   或整个条目省略。原文说「否认」「无」「未见」「阴性」→ 填「否」；
   「有」「阳性」「存在」→ 填「是」。不要把「否认」原样写进去。
2. 数值只写数值本身，单位放进 `单位` 字段。
   原文「高密度脂蛋白胆固醇 0.93mmol/L」且清单列名已标单位(mmol/L)
   → 值=0.93，单位=mmol/L。
3. 时间保留原文精度（2024-09-14 14:03），不要补全也不要截断。
4. 血压、身高等一条原文含多个目标列的，**拆成多条**，各自带自己的出处。
   例：「血压 159/79mmHg」→ 收缩压（mmHg）=159、舒张压（mmHg）=79。
5. 值控制在 40 字以内。超长的原文概括成要点，不要整段抄。
   ★ 例外：`入院查体`、`出院查体` 是**长文本字段**，不适用 40 字限制 ——
     原样照抄体征原文（去掉多余换行就行），不要概括成要点。
     确实过长时（超过 500 字）保留**全部阳性体征 + 神经系统部分**，
     其余按原文顺序压缩，但不要整段丢弃。
   ★ 例外：`主诉` 照抄原文那一句（它本来就短）。

════════════════════════════════════════════════════════════
【三个长文本列在原文哪里】

`主诉` / `入院查体` / `出院查体` 在原文里都是有标签的，照标签取：

  `主诉`     ← 入院记录里「主诉：」后面那一句。
               原文「主诉：右侧面部、右手指麻木57小时」
               → 值 = 右侧面部、右手指麻木57小时
  `入院查体` ← 「入院查体：」或「入院后查体：」后面那一整段体征；
               入院记录「体格检查」的正文也归这一列。
               原文「入院查体：脉搏81次／分，呼吸18次／分，血压155／99mmHg，
                    体温36.7℃，神志清，精神可…」→ 整段进 `入院查体`
  `出院查体` ← 出院记录里「出院情况：…查体：」**「查体：」之后**那一段。
               原文「出院情况：患者现右侧面部、右手指麻木较前好转，查体：
                    脉搏71次／分，呼吸18次／分…」
               → 值 = 脉搏71次／分，呼吸18次／分…（不含「出院情况」那半句）

  这三列的 `值` 就是上面那段原文，**不要**再往里塞 `所见` / `结论` 等字段。
  体征段里如果出现血压，照样按第 4 条另拆出收缩压 / 舒张压两条；
  但 `入院查体` 这一段本身仍然整段保留，两条互不影响。

════════════════════════════════════════════════════════════
【输入长什么样】

每段开头有一个块引用，形如 【text p12-b3】/【table p29-b4】，p 是页码，b 是块号。
文本里可能夹着这几类注释，表示「这里原本有内容但没取到」，当成缺失，不要脑补：
    <!-- 缺失 p3-b15：table，VL 服务不可用 -->
    <!-- 截断 p7-b9：table，内容被截断 -->
    <!-- 占位 p8-b11：图片（无文本） -->
表格以网格文本给出，列用 | 分隔，第一行通常是表头，末尾可能有「异常项：…」。

【硬性规则】

1. 只依据原文，绝不补充原文里没有的内容。
2. 出处必须来自正文里**真实出现过**的块引用，一个字符都不能改。
3. 标注为缺失/截断/占位的位置不要生成条目。若整章都缺失，
   相关=false、条目=[]。
4. 条目最多 80 条。超出时保留临床价值最高的（诊断、用药、关键化验优先）。
5. **不要重复**。同一列的同一个值只写一条；已经写过的内容不要再汇总一遍。
   ★ 病历**每一页的页眉/页脚**往往重复同一份患者基本信息（姓名 / 性别 /
     年龄 / 病案号 / 床号 / 病区 / 入院时间 等）。这一章里已经写过的，
     **后面再遇到就跳过，不要再输出一遍**。同一张化验单在多页重复出现时，
     只取信息最全的那一处。
6. 主诉的类别填「主诉」、项目填「主诉」（它现在就在列名清单的「本次发病」里）。
7. 只输出 JSON。不要解释，不要 markdown 代码块，不要  thinking。
【字段章节归属·必须遵守】
1. 既往××（既往史类字段）只能从「既往史」段或「入院记录」里的既往史部分提取。
2. 严禁从「鉴别诊断」「诊断依据」「诊疗计划」等推理/说明性段落提取既往史。
3. 鉴别诊断里说"本病可能性小""排除本病"不等于病人既往没有这个病。
4. 出院××（出院情况类）只能从「出院记录」提取；入院××只能从「入院记录」或「首次病程记录」提取。
5. 找不到对应章节时留空，不要从其他章节凑。
